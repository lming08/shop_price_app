# 包姐便利店 · 查价 App

给店主和家人用的查价小工具：**对着商品条码一扫，立刻大字显示价格**。

- 无需后端服务器、无需联网（首次打开后完全离线可用）
- 数据存在每台手机本地，只供店主及家人使用
- 适老化设计：大字体、大按钮、超大价格展示
- 支持安卓和 iPhone，通过浏览器"添加到主屏幕"当 App 用

## 功能一览

| 功能 | 说明 |
| --- | --- |
| 扫码查价 | 相机对准条码自动识别，命中即显示大字价格 |
| 手动输入条码 | 条码磨损扫不出来时兜底 |
| 商品管理 | 扫码添加（商品页主入口，已建档的条码会直接显示）/ 手动添加 / 编辑 / 删除 / 按名称或条码搜索；编辑时表单内也能「扫条码」填入 |
| 商品拍照 | 添加/编辑时拍照存档，查价和列表里能看到商品照片 |
| Excel 批量导入 | 把纸质价格表录成 Excel 一次性导入，支持模板下载 |
| 导出价格表 | 导出 Excel，可打印一张新的纸质价格表备用 |
| 备份 / 恢复 | 一键导出含照片的备份文件，换手机或复制给家人 |
| 改价格 | 查价结果页直接改价，价格变了不用翻档案 |

## 目录结构

```
shop_price_app/
├── index.html          # 应用页面（含全部界面模板）

├── lib/                # 本地化的第三方库（Vue3、html5-qrcode、SheetJS）
├── css/app.css         # 适老化样式
├── js/
│   ├── db.js           # IndexedDB 数据层 + 图片压缩工具
│   ├── scanner.js      # 扫码封装（原生 BarcodeDetector 优先，html5-qrcode 兜底）
│   ├── excel.js        # Excel/CSV 导入导出（支持 UTF-8 与 GBK 编码）
│   ├── backup.js       # JSON 备份恢复（含照片）
│   └── app.js          # Vue 应用主逻辑
└── test/
    ├── logic-test.html # 数据逻辑自测（浏览器打开即跑，标题显示结果）
    └── scan-test.html  # 条码解码自测（本地生成 EAN-13 验证解码链路）
```

## 本地试跑

```bash
cd shop_price_app
python3 -m http.server 8765
# 浏览器打开 http://127.0.0.1:8765
```

自测页：打开 `http://127.0.0.1:8765/test/logic-test.html` 和 `/test/scan-test.html`，

## 正式使用：必须部署到 HTTPS

浏览器只允许 **HTTPS 页面**（或本机 localhost）调用摄像头，所以正式使用前要把整个
文件夹上传到任意静态网站托管，例如：

- **GitHub Pages**：新建仓库 → 上传全部文件 → 开启 Pages，得到 `https://xxx.github.io/仓库名/`
- **阿里云 OSS + CDN**：把文件夹作为静态网站托管，绑定已备案域名
- **Vercel / Netlify**：拖拽文件夹即可得到 https 网址

> 更新版本时：改完文件后把 `sw.js` 里的 `CACHE = 'baojie-price-v2'` 版本号 +1，
> 老用户下次打开才能拿到新版本。

## 家人手机怎么装（添加到主屏幕）

- **安卓（Chrome/多数国产浏览器）**：打开网址 → 浏览器右上角「⋮」→「添加到主屏幕」/「安装应用」
- **iPhone（必须用 Safari 打开）**：点底部中间「分享 ⬆️」→ 往下找「添加到主屏幕」→「添加」

安装后桌面出现「包姐查价」图标，点开即全屏运行，无网也能用。

## Excel 导入格式

第一行为表头，列顺序不限（程序按表头自动识别）：

| 条形码 | 商品名称 | 价格(元) | 单位 | 备注 |
| --- | --- | --- | --- | --- |
| 6901236343104 | 农夫山泉 550ml | 2 | 瓶 | |
| 6920584430052 | 可口可乐 330ml | 3 | 罐 | |
| | 茶叶蛋 | 1.5 | 个 | 无条码，手动添加 |

- 「条形码」「价格」表头也可写「条码」「单价」「售价」等，能自动匹配
- 没有 Excel？设置页里有「下载导入模板」，填好再导入
- 便利店商品包装上印的就是 EAN-13 条形码，收银台扫码枪扫出来的数字就是它；
  录入时**务必照包装上的数字抄**，这样扫出来才能对上
- 无条码的商品（散装、现做）可以不填条形码，查价时用搜索找
- 支持两种编码：UTF-8 和国内 Excel 常见的 GBK/GB2312 导出格式

## 数据存在哪里？怎么换手机？

纯单机设计：**数据只存在本手机的浏览器里**，家人各自维护各自的商品库。

换手机或复制给家人：旧手机「设置 → 导出备份文件」（一个 json 文件，含照片）→
通过微信/隔空投送发到新手机 → 新手机打开 App，「设置 → 从备份文件恢复」选择该文件。

> 注意：手机浏览器"清除浏览数据"会清掉商品库！定期导出一份备份更保险。
> 想要全家人共享同一份数据、实时同步，需要加后端服务，属于后续升级方向。

## 技术说明

- 纯静态页面，零构建：改完文件刷新即生效
- 条码识别：安卓 Chrome 走原生 `BarcodeDetector`，iOS 走 html5-qrcode（ZXing）
- 存储：IndexedDB（商品与照片），localStorage（最近查询记录）
- 照片在入库前压缩到最长边 900px 的 JPEG，控制存储体积
